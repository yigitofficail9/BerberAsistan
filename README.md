# Kuaför & Berber Asistanı ✂️💈

> Berberler ve kuaförler için geliştirilmiş; yapay zeka/sesli komut desteği, WhatsApp otomatik hatırlatıcı, kasa, veresiye ve çırak primi takibi yapabilen modern web tabanlı yönetim paneli.

---

## 🚀 Proje Hakkında

Bu uygulama, işletme sahiplerinin (berber/kuaför) günlük iş akışlarını en aza indirerek randevu, kasa, veresiye ve personel yönetimini tek bir ekrandan kolayca yönetmesini sağlar. Şık koyu tema (Dark Mode) tasarımı ve sesli komut entegrasyonuyla pratik bir kullanıcı deneyimi sunar.

## ✨ Temel Özellikler

- **Sesli Komut Asistanı:** Mikrofonu kullanarak sesle randevu oluşturma, kasa sorgulama veya veresiye yazma imkanı.
- **Akıllı Randevu Yönetimi:** Günlük, haftalık ve aylık takvim görünümü, müşteri bilgileri ve hizmet seçimi.
- **WhatsApp Hatırlatıcı:** Randevular için otomatik WhatsApp mesaj planlama ve hatırlatma entegrasyonu.
- **Kasa & Finans Takibi:** Giren/çıkan nakit ve kart ödemelerinin anlık takibi.
- **Veresiye Defteri:** Borçlu müşterilerin listesi ve ödeme alma işlemleri.
- **Çırak / Personel Yönetimi:** Çalışanların haftalık ücret, prim (%20) ve avans hesaplamaları.
- **Özelleştirilebilir Ayarlar:** Çalışma saatleri, dükkan adı ve hizmet fiyatlarını esnekçe güncelleme imkanı.

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, CSS3 / Modern Tailwind, JavaScript
- **Arayüz Tasarımı:** Dark Mode & Glassmorphism UI
- **Özellikler:** Web Speech API (Sesli Komut), WhatsApp API Entegrasyonu
